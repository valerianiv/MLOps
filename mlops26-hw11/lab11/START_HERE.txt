ЛАБОРАТОРНАЯ №11 — С ЧЕГО НАЧАТЬ

1. Открыть README.md. В нём пошагово описана установка Ubuntu в WSL2 и Docker Desktop.
2. Скопировать папку lab11 из Windows в ~/lab11 внутри Ubuntu.
3. Все следующие команды выполнять в терминале Ubuntu:

   cd ~/lab11
   bash scripts/install-tools.sh
   bash scripts/lab.sh setup
   set -o pipefail
   bash scripts/lab.sh all 2>&1 | tee run.log

4. Открыть report.html. Графики и таблицы появятся после реальных прогонов.
   Проверить PASS/FAIL и выполнить сверку Prometheus по разделу 5 README.md.
5. Вписать ФИО, группу, итоговый репозиторий/коммит и кейс компании из видеолекции.
6. Скопировать готовые результаты в Windows и самостоятельно загрузить в репозиторий.
7. После сохранения результатов: bash scripts/lab.sh cleanup

Ожидаемое время опытов: примерно 45–70 минут. Первая установка — дополнительно.
Ноутбук подключить к питанию, не переводить в сон. GPU не нужен.

Код прошёл 8 локальных проверок. Kubernetes-прогоны должны выполняться на ноутбуке.
Существующий report.html — структура отчёта без выдуманных результатов.
